# Project 1 – Progressive Electricity Billing System

## Description
The Progressive Electricity Billing System is a Python-based project that calculates electricity bills according to the units consumed. It uses different electricity slab rates, fixed charges, and a 5% surcharge to calculate the final bill. It also compares the current bill with the previous month's bill to identify unusual increases.

## Objectives
- Calculate electricity charges based on units consumed.
- Apply progressive electricity slab rates.
- Calculate fixed charges and surcharges.
- Generate the final electricity bill.
- Identify unusual increases in monthly bills.

## Concepts Used
- Variables and Data Types
- User Input
- Arithmetic Operators
- Conditional Statements (if, elif, else)

## Electricity Tariff Assumptions
- 0–100 units: ₹2 per unit
- 101–200 units: ₹3 per unit
- Above 200 units: ₹5 per unit
- Fixed Charge: ₹50
- Surcharge: 5% of energy charges

## Sample Output
```text
Enter electricity units: 80
Enter previous bill: 200

Energy Charge: Rs. 160.00
Fixed Charge: Rs. 50.00
Surcharge: Rs. 8.00
Final Electricity Bill: Rs. 218.00
Bill Status: Normal Increase
```

## How to Run
1. Open the project folder in VS Code.
2. Open the Python source file.
3. Run the program.
4. Enter electricity units and the previous bill amount.
5. View the final electricity bill.

This project demonstrates the practical application of Python programming concepts to calculate electricity bills, apply slab rates, and compare monthly bill amounts.
